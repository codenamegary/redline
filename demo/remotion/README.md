# redline demo video

A Remotion composition that stitches the redline demo into one MP4:

1. Terminal recording (`demo/01-terminal.mp4`), cut into four labeled sections with a 16x time-lapse over the build
2. Redline review UI recording (`demo/02-redline.mp4`): the opening 7s at 1x with punch-in zooms on the mouse actions, then the rest of the session at 2x
3. Outro card

Canvas is 1440x810 at 30fps. Both recordings are 16:9, so they scale to the canvas without letterboxing. The ember theme matches the artifact.

## Use

```sh
cd demo/remotion
bun install
bun run prepare-assets   # hardlinks the recordings into public/
bun run studio           # preview in the browser
bun run render           # writes out/redline-demo.mp4
bun run render:docs      # renders straight to docs/redline-demo.mp4 (embedded in the repo README)
```

## Adjust the cut

All timing lives in `src/timings.ts`:

- `terminalCuts` - where each section starts and ends in the terminal recording, plus playback rate. Keep the rate at 16 or below: the Studio preview plays video through a browser media element, which throws above 16x
- `reviewCuts` - spans of the review UI recording, their rates, punch-in zooms, and synthetic cursors. The camera needs 0.25s (timeline) per zoom ease-in/out, so a zoom starts at or after its cut begins. Element-click beats play at 1x, typing beats at 4x, connective tissue at 2x. Split or trim cuts to change what the demo covers

The review recording's audio is silent, so the composition plays it muted. Remove the `muted` prop in `src/review.section.tsx` if a future recording has sound worth keeping.
